# Кредитный скоринг: предсказание серьёзной просрочки

Пет-проект на реальных (анонимизированных) данных финтех-компании — предсказание вероятности серьёзной просрочки (90+ дней) в течение 90 дней после выдачи займа. Изначально сделан как решение соревнования по кредитному скорингу, оформлен здесь как самостоятельный проект.

**Метрика:** ROC-AUC. **Итоговый результат (5-fold CV):** ≈ 0.83 (бленд), log_reg ≈ 0.828, LightGBM ≈ 0.828.

## Данные

Четыре источника, агрегированные на уровне клиента:
- `train`/`test` — заявки на займ
- `transactions` — история транзакций клиента
- `bureau` — внешняя кредитная история
- `previous_loans` — прошлые займы клиента

Сами данные в репозиторий не включены (условия соревнования не позволяют их публично распространять) — `data/` в `.gitignore`. Ноутбук ожидает эти файлы в `data/` с оригинальными именами.

## Подход

1. **EDA** — для каждого признака: p-value (ttest/chi2), сила эффекта (Cramér's V / η², с поправкой на ожидаемый уровень V при чистом шуме) и Information Value через WoE-биннинг. Финальный отбор признаков — по порогу IV. Отдельно выявлена и удалена утечка (признак, кодирующий информацию, недоступную на момент подачи заявки).
2. **Признаки** — сырые агрегаты по клиенту (суммы/средние/std по транзакциям, кредитной истории, прошлым займам) + отдельный WoE-набор для логрегрессии.
3. **Модели** — бленд логистической регрессии (на WoE-признаках, интерпретируемая) и LightGBM (на сырых признаках, с нативной обработкой пропусков и категорий). Также тестировался RandomForest — исключён из финального решения, так как стабильно уступал по качеству и портил бленд.
4. **Валидация** — StratifiedKFold (5 фолдов), подбор гиперпараметров через GridSearchCV.
5. **Интерпретируемость** — коэффициенты логрегрессии, SHAP для LightGBM, сверка важности признаков с IV-таблицей, PSI между train и test для проверки стабильности распределения скора.

## Структура репозитория

```
competition.ipynb    — весь пайплайн: EDA → фичи → модели → интерпретируемость → submission
requirements.txt     — зависимости
submission.csv       — предсказания на test
data/                — не включена в репозиторий (см. выше)
```

## Как запустить

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Положить файлы данных в `data/`, открыть `competition.ipynb` и выполнить все ячейки — на выходе получится `submission.csv`.
